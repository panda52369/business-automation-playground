# Decision Lab

[Open the interactive playground](https://panda52369.github.io/business-automation-playground/).

Try three business decisions in your browser:

- Freight qualification: validate and score a sample shipping inquiry.
- Order inventory: explore reservations, shortages, and unknown-item holds.
- Freight audit: compare a sample invoice with its quote and shipment evidence.

These demos use real decision functions with synthetic examples. Each run starts fresh. No email, payment, warehouse dispatch, OCR, or external API integration takes place. Inputs stay in memory and are not stored by the app. The demos continue working offline after the page has loaded; an initial connection is required.

This repository contains the static playground only. Backend services and workflow runtimes are not included. See [notices](notices.txt) for the code and fixture limitations. No additional reuse license is granted.

The content build identifier and asset hashes are available in [metadata.json](metadata.json).
